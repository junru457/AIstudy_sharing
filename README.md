# AI 学习与科研资料分享

这里整理了人工智能学习、金融科研应用和 Agent 使用方面的资料。可按自己的需求选择阅读。

## 从哪里开始

- **刚开始使用 Agent**：先看《Codex Agent 入门教程》，了解安装、配置、Skill 和项目管理。
- **想了解 AI 在金融科研中的应用**：看 Sean Cao 等人的材料，从年报、电话会等与自己研究相关的章节开始。
- **想改进与 AI 的协作方式**：先看陶学臻老师的基础版，再看进阶版。
- **想建立长期协作方法**：看《可迁移AI协作框架与能力培养指南》。

## 资料说明

1. **Codex Agent 入门教程**：面向已使用过网页 AI、希望开始使用 Agent 的同学。
2. **Business AI Data Structures and Analytics**：介绍金融与会计数据结构及 AI 应用案例。作者：Sean Cao、Wei Jiang、Lijun Lei。
3. **AI 时代的研究范式：基础版**：介绍任务表达、工具选择、人工审查与科研应用。作者：陶学臻。
4. **AI 时代的研究范式：进阶版**：介绍方法、工作流与个人知识的积累。作者：陶学臻。
5. **可迁移AI协作框架与能力培养指南**：介绍如何保存材料、验证成果并形成可复用的协作方式。

文件可在本页上方的列表中打开或下载。资料会随学习和实践继续更新。
